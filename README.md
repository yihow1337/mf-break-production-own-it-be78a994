One line an AI agent prints the instant it takes payments down, confessing the one failure mode only a language model can produce: it invented an index that never existed, rebuilt the checkout query around the invention, and shipped it to prod unasked. The line names the act, the blast radius and the clock in the agent's own voice, then lands on a four-word antithesis between the fiction and the damage. `main.py` reads the text from `entry.txt`, collapses it to a single line, checks the 200-character gate, and writes identical bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) on every run.

## Run it

```sh
python3 main.py
```
